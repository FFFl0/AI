# VoiceText — своя нейросеть для извлечения текста из видео по озвучке

Программа берёт видео (mp4, mkv, avi, mov, webm…) или аудио, извлекает звуковую дорожку
и распознаёт речь **собственной нейросетью**. Готовые модели (Whisper и т. п.) не используются:
архитектура, обучение и декодирование написаны здесь с нуля на PyTorch.

Результат сохраняется в форматах:
- **JSON**: весь текст, фразы и каждое слово с временем начала и конца и уверенностью модели;
- **SRT / VTT**: субтитры, которые можно подключить к видео;
- **TXT**: просто текст.

Язык (русский или английский) определяется автоматически.

## Как это устроено

```
видео ──ffmpeg──► звук 16 кГц ──► нарезка по паузам (куски ≤ 20 с)
      ──► лог-мел спектрограмма (80 полос, 100 кадров/с)
      ──► нейросеть Conformer (свёртки + self-attention), выход: 25 кадров/с
      ──► CTC-декодирование ──► символы ──► слова с таймкодами ──► фразы-субтитры
```

| Файл | Что делает |
|---|---|
| `voicetext/audio.py` | извлечение звука из видео, спектрограмма, детектор пауз |
| `voicetext/tokenizer.py` | словарь символов (кириллица, латиница, цифры), определение языка |
| `voicetext/model.py` | нейросеть: Conformer-энкодер + CTC-голова, три размера |
| `voicetext/data.py` | загрузка данных, аугментации (SpecAugment, громкость, шум) |
| `voicetext/train.py` | обучение с нуля, валидация (CER/WER), сохранение лучшей модели |
| `voicetext/decode.py` | декодирование CTC, таймкоды слов, группировка в субтитры |
| `voicetext/transcribe.py` | весь конвейер «видео → результат» |
| `voicetext/web.py` | веб-интерфейс (Gradio) |
| `voicetext/cli.py` | командная строка |

## Установка

Нужны **Python 3.10+** и **ffmpeg**.

```bash
pip install -r requirements.txt        # только командная строка
pip install -r requirements-web.txt    # плюс веб-интерфейс
```

Если есть видеокарта NVIDIA, поставьте PyTorch с CUDA по инструкции с pytorch.org.

## Что нужно, чтобы нейросеть хорошо распознавала речь

Нейросеть, написанная с нуля, сначала ничего не умеет: её нужно **обучить**.
Качество зависит от трёх вещей.

### 1. Данные (самое важное)

Нужны пары «аудиозапись — точный текст того, что сказано». Ориентиры:

| Объём данных | Ожидаемый результат |
|---|---|
| 1–10 ч | модель учится, но для реальных видео почти бесполезна |
| 100 ч | разборчивый текст, много ошибок (CER ~15–25 %) |
| 500–1000 ч | хорошее качество на чистой речи (CER ~5–10 %) |
| 3000+ ч | близко к коммерческим системам |

Бесплатные открытые наборы:
- **Mozilla Common Voice** (русский ~200+ ч, английский ~2500+ ч): commonvoice.mozilla.org
- **Golos** (Сбер, ~1200 ч русской речи)
- **Russian Open STT** (~20 000 ч, разное качество)
- **LibriSpeech** (английский, 960 ч)
- **Свои данные**: видео с точными субтитрами. Это лучший вариант, если распознавать нужно похожие видео.

### 2. Вычислительные ресурсы

| Модель | Параметров | Где обучать | Время на 1000 ч данных |
|---|---|---|---|
| `small` | 6.6M | CPU (медленно) / любая GPU | ~1–2 дня на одной GPU |
| `medium` | 26M | GPU от 12 ГБ (RTX 3060/4070 и выше) | ~3–5 дней на одной GPU |
| `large` | 110M | GPU от 24 ГБ или несколько GPU | ~1–2 недели |

Распознавание уже обученной моделью работает и на обычном CPU.

### 3. Время на эксперименты

Подбор размера модели, learning rate и числа эпох — нормальная часть работы.

## Пошагово

### Шаг 0. Проверка, что всё работает (5 минут, без реальных данных)

Нужен `espeak-ng` (синтезатор речи), чтобы сделать игрушечный набор данных:

```bash
python scripts/make_demo_data.py data/demo
python -m voicetext prepare folder data/demo/clips --out data/demo --val-fraction 0
python -m voicetext train --train data/demo/train.jsonl --out checkpoints/demo --epochs 120 \
    --batch-seconds 60 --warmup 100 --lr 2e-3 --dropout 0 --no-augment --workers 0 --log-every 0
python -m voicetext transcribe data/demo/demo.mp4 -m checkpoints/demo/best.pt --print
```

Модель запоминает 20 фраз и распознаёт демо-видео почти правильно. Это проверка
того, что конвейер работает, а не настоящая модель.

### Шаг 1. Подготовка данных

```bash
# Common Voice (распакованный архив с clips/ и train.tsv, dev.tsv)
python -m voicetext prepare common_voice /path/to/cv-corpus/ru --out data/ru --convert

# Своя папка: пары video1.mp4 + video1.txt, audio2.wav + audio2.txt ...
python -m voicetext prepare folder /path/to/my_data --out data/my --convert

# Любой JSONL со ссылками на аудио и текстом (Golos и др.)
python -m voicetext prepare jsonl /path/to/manifest.jsonl --out data/golos --text-key text --convert
```

`--convert` перекодирует всё в WAV 16 кГц, и обучение идёт в разы быстрее.
Каждая фраза должна быть **не длиннее 25 секунд**: длинные записи нарежьте заранее.
Несколько наборов можно объединить, просто склеив их `train.jsonl`.

### Шаг 2. Обучение

```bash
python -m voicetext train --train data/ru/train.jsonl --val data/ru/val.jsonl \
    --size medium --epochs 60 --out checkpoints/ru
```

- Каждую эпоху выводятся CER (ошибка по символам) и WER (ошибка по словам).
- Лучшая модель сохраняется в `checkpoints/ru/best.pt`, последняя в `last.pt`.
- Продолжить прерванное обучение: `--resume checkpoints/ru/last.pt`.
- Не хватает памяти GPU: уменьшите `--batch-seconds` и добавьте `--grad-accum 4`.

### Шаг 3. Распознавание видео

```bash
# Командная строка: файлы или целые папки
python -m voicetext transcribe video.mp4 -m checkpoints/ru/best.pt -f json srt vtt
python -m voicetext transcribe /videos/ -m checkpoints/ru/best.pt -o results/

# Веб-интерфейс: откройте http://127.0.0.1:7860
python -m voicetext web -m checkpoints/ru/best.pt
```

## Ограничения текущей версии и что можно улучшить

- Текст выдаётся **без пунктуации и заглавных букв** (так модель обучается на нормализованном тексте).
  Можно добавить отдельную модель расстановки знаков препинания.
- Декодирование жадное. Beam search с языковой моделью (n-gram или нейросетевой) обычно
  снижает ошибки на 10–20 %.
- Детектор пауз простой, по энергии сигнала. На видео с громкой музыкой лучше обучить нейросетевой VAD.
- Язык определяется по алфавиту распознанного текста (кириллица или латиница). Для других
  языков нужно расширить словарь в `tokenizer.py` и обучить модель на соответствующих данных.
